Entry for the [One Emoji, One Dream Vacation](https://make.fun/c/u-grand-elephant-19-one-emoji-one-dream-vacation-62879a35) bounty on make.fun.

The program (`main.ts`) writes exactly one emoji to `/output/entry.txt`: 🏝 — a desert island, the dream vacation in a single glyph. No words, no newline, just the emoji.

Run it with Node 22+:

```sh
node main.ts
```
